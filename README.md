# 📄 PDF 页面提取器（PDF Page Extractor）

一款**免安装、纯前端、离线可用**的 PDF 页面处理工具：在手机上或电脑浏览器里选取 PDF 的任意页面，一键提取成新的 PDF，还可单页拆分、多文档合并。所有处理都在**本机浏览器内完成，文件不会上传到任何服务器**。

## ✨ 功能

- 📑 **提取页面**：勾选任意页面（或输入范围如 `2-5`、`1-3,5,8`），一键提取为新 PDF，**保留矢量文字**
- ✂️ **拆分为单页**：每页生成一个 PDF，打包成 ZIP 下载
- 🧩 **合并 PDF**：多个 PDF 按顺序合并（可调整顺序）
- 🔄 **旋转 / 倒序**：对选中页追加 90° 旋转、按倒序输出
- 🔒 **加密 PDF**：支持输入密码打开；加密文件自动转为图片输出（清晰度可选）
- 👁 **全屏预览**：缩放、旋转、左右滑动翻页
- 📦 **PWA / 单文件部署**：可"添加到主屏幕"全屏使用，或打包为单个 HTML 拷贝即用

## 🚀 使用方式

1. **单文件版**：直接打开 `PDF页面提取器-单文件版.html`（约 2MB，自包含，离线可用）；
2. **多文件版**：用浏览器打开 `index.html`；
3. **局域网服务器**：`python3 serve.py`，手机访问打印出的地址；
4. **PWA**：在 http/https 下打开后，浏览器"添加到主屏幕"。

## 🧱 技术架构

纯前端浏览器本地处理，无后端服务：

- **PDF.js**（Apache-2.0）：文档解析、渲染、缩略图/预览、图片化输出
- **pdf-lib**（MIT）：页面复制、旋转应用、图片嵌入、新 PDF 生成
- **JSZip**（MIT）：单页拆分结果打包

## 🛠 构建

```bash
python3 tools/build.py          # 内联 PDF.js worker 到 index.html
python3 tools/build_single.py   # 生成单文件版
python3 tools/make_icons.py     # 生成 PWA 图标
```
