# 📄 PDF 页面提取器（手机版）

一个**免安装、纯前端、离线可用**的 PDF 页面工具：在手机上（或电脑浏览器里）选取 PDF 的任意页面，提取成一个新 PDF。
所有处理都在**本机浏览器内完成，文件不会上传到任何服务器**。

---

## ✨ 功能

| 功能 | 说明 |
|---|---|
| 📑 **提取页面** | 勾选任意页面（或输入范围如 `2-5`、`1-3,5,8`），一键提取为新 PDF，**保留矢量文字** |
| 🔄 旋转页面 | 对选中页追加 90° 旋转后再提取 |
| 🔀 倒序提取 | 按选中页倒序输出 |
| ✂️ 拆分为单页 | 每页生成一个 PDF，打包成 ZIP 下载 |
| 🧩 合并 PDF | 把多个 PDF 按顺序合并（可上下调整顺序） |
| 🔒 加密 PDF | 支持输入密码打开；加密文件自动转为图片输出（清晰度可选） |
| 👁 预览 | 点页面上的眼睛图标全屏预览，可缩放、旋转、左右滑动翻页 |
| 📦 PWA | 支持"添加到主屏幕"，全屏像 App 一样使用，离线可用 |
| ⚡ 链接打开 | 可直接输入 PDF 网址打开（需网站允许跨域） |

---

## 📱 在手机上使用（三种方式）

### 方式一：只拷一个文件（最简单，Android）
1. 把 **`PDF页面提取器-单文件版.html`** 这一个文件发到手机（微信文件传输 / USB / 网盘均可）。
2. 用文件管理器找到它，选择"**用 Chrome / 浏览器打开**"。
3. 完事。文件全程留在本机，无需联网。

> 单文件版已把全部代码打包进一个 HTML（约 2MB），什么都不用管，拷走即用。
>
> iPhone 的 Safari 不支持直接打开本地 HTML 文件，请用方式三（局域网）。

### 方式二：整个文件夹 + 添加到主屏幕（当 App 用）
- 适合想获得 **PWA 离线缓存 / 全屏 App 体验** 的用户（需要把文件夹放在服务器上，file:// 下 PWA 不生效）。
- Android Chrome：打开页面 → 菜单 → **添加到主屏幕**；iPhone Safari：分享 → **添加到主屏幕**。

### 方式三：电脑起局域网服务器（Android / iPhone 通用）
电脑上（需装有 Python）：
```bash
cd pdf-page-extractor
python3 serve.py
# 或：python3 -m http.server 8000
```
手机和电脑连**同一个 Wi-Fi**，用手机浏览器打开电脑 IP，例如 `http://192.168.1.5:8000`（启动时会打印地址）。

## 🖱 操作步骤（提取页面）

1. 打开页面 → 点击"📂 点击选择 PDF 文件"选择你的 PDF（或拖进来 / 粘贴链接）。
2. 等缩略图出现后，**点页面卡片**勾选要提取的页；
   也可以用"快速添加"输入范围：`起 2 至 5`，或直接填 `1-3,5,8-10`。
3. 点底部 **"提取为 PDF"**，浏览器会自动下载新文件，命名如 `原文件名_第2-5页.pdf`。

小技巧：
- 点 **反选** 可以快速"删除"不需要的几页（保留其余全部）。
- 需要把每页单独存文件时，点 **"拆分为单页 ZIP"**。
- 需要拼合多个文档时，切到 **"合并 PDF"** 标签。

## ⚠️ 注意事项

- **加密 PDF**：打开时会要求输入密码；由于浏览器技术限制，加密文件提取时会把页面**转为图片**输出（文字不可再选），清晰度可在"高级设置"里调（普通 2x / 高清 3x）。
- **链接打开**：多数网站禁止跨域，粘贴网址可能失败，属正常现象，请先下载到本地再打开。
- **表单/批注**：普通 PDF 提取会保留文字、图片、版式；个别带交互表单/批注的文档，提取后可能丢失这类元素（内容不受影响）。
- **iOS 下载**：Safari 下载后会出现在"文件"App 的"下载"里，点开即可预览/分享。
- 页面很多时缩略图按需加载，滚动到才渲染，请耐心等待。

## 📁 文件结构

```
pdf-page-extractor/
├── PDF页面提取器-单文件版.html   # ★ 推荐：拷这一个文件就能用（自包含约 2MB）
├── index.html                    # 多文件版入口（配服务器 + PWA 时用）
├── app.js                        # 业务逻辑
├── manifest.webmanifest          # PWA 清单
├── sw.js                         # 离线缓存
├── serve.py                      # 局域网服务器（可选）
├── icons/                        # 图标
├── lib/                          # pdf.js / pdf-lib / jszip
└── tools/                        # 构建脚本
    ├── build.py                  # 内联 worker 到 index.html
    └── build_single.py           # 生成单文件版
```

> **单文件版 vs 多文件版**：核心功能完全一样。区别只在 PWA——
> 单文件版直接双击/file:// 打开，无需任何设置，但没有"添加到主屏幕"的离线缓存；
> 想当 App 装到桌面，就用多文件版配 `serve.py`（方式三）。

## 🔧 重新构建（可选）

如果替换了 `lib/` 里的库，需重新把渲染引擎内联进 `index.html`：
```bash
python3 tools/build.py
```
